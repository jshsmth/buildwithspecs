# Home surface

Mode: Persuade, with Read sections. Audience: developers adopting the workflow. Primary action: open the starter-kit setup page and download a usable archive. Secondary action: explore a complete notification-preferences example.

## Direction contract

THESIS: An engineering field guide that demonstrates how one feature moves from context to verified work. Actual documents carry the explanation.

OWN-WORLD: Warm paper, near-black ink, violet annotations, Newsreader editorial display type and DM Sans body. Fine rules, square document surfaces, unboxed reading sections, and generous margins.

STORY: Understand the method, inspect the example, distinguish project knowledge from reusable skills, then adopt the kit. Clearly label illustrative evidence.

FIRST VIEWPORT: Compact masthead above a large two-line editorial promise. A short introduction and violet starter-kit action sit to its left; a narrow guide note sits right. A full-width six-stage rail leads into a document workbench visible at the fold. The signature interaction changes both the stage explanation and its real artifact with a brief page-settling transition. Mobile uses a wrapping stage selector above the document.

FORM: User-approved field guide plus artifact viewer, selected in conversation; no random seed used because the user explicitly approved this concept. Code-led build confirmed by the user.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Boundaries
Preserve existing download URL as a legacy resource. No deployment or external tracker writes. No company-specific source, invented metrics, claims of universal client support, or fake install commands. Keyboard-accessible progressive enhancement; meaningful content without JavaScript. Verify desktop and mobile, every workbench stage, setup links, download contents, and production build.
