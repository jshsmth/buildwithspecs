# Maintain context

Identify the verified change and the existing topic that owns it. Update that page rather than creating a competing source of truth. Separate current behaviour, accepted decisions, proposals, and dated operational evidence.

Lead with the current contract and link to detailed procedures only when needed. Keep private data and credentials out of documentation.

Follow the repository's documentation conventions and checks. If an indexing tool generates navigation, refresh it through that tool rather than editing generated rows by hand. With a maintained Markdown index, update the affected links and entry points directly.

Finish when the changed behaviour is accurately documented, relevant routing still reaches it, and required documentation checks have passed or have a specific reported blocker.
