# Product

<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
Developers adopting a repeatable agent workflow in their own repositories.

## Product Purpose
Build with Specs teaches how project context, planning, specifications, tickets, implementation, and verification connect. Success is a developer understanding the method and adapting the starter kit to a real project.

## Positioning
A practical field guide with an inspectable worked example and reusable starter materials. Specifications remain central within a wider development workflow.

## Capabilities and Constraints
Astro static site deployed through the existing Vercel adapter. Provide a functional starter-kit download and setup guidance. Preserve the brand name and creator links. Examples are illustrative and must not imply measured results, real deployments, or company endorsement. The downloadable kit contains original generic templates, not private repository content or redistributed third-party skills.

## Operating Context
Teach indexed project knowledge independently of any vendor. Linked Markdown, search, and wiki tools are implementation choices; Plasma Wiki is one optional example. AGENTS.md routes tasks and constraints; skills describe procedures; specs and tickets describe a change. Shared skills and repository context have different ownership. Installation paths and command invocation depend on the agent client.

## Brand Commitments
Retain Build with Specs and the ghost mark. The user approved an engineering field guide with an interactive artifact viewer, warm paper, near-black text, and restrained violet accents. Build directly in code.

## Evidence on Hand
The existing page and source were inspected. sm-app-new and sm-auth demonstrated repository-local Plasma Wiki documentation, task routing, user-level skills, tracker boundaries, and separate validation/delivery evidence. Public examples must be independently authored and labelled illustrative.
